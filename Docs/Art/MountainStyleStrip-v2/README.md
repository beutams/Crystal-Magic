# 山正面样条 v2：少量细节

基于用户确认的 `MountainStyleStrip-v1` 增加少量岩面细节，另存此目录，不覆盖 v1，不改游戏内资源、RuleTile 或代码。

## 变化与保留

- 正面山脚：增加短裂隙与小型岩面断口，30/256 个像素变化。
- 山腰：增加局部裂纹分支和岩层缺口，21/256 个像素变化。
- 山顶前缘：增加少量轮廓内部缺口与下延裂纹，8/256 个像素变化。
- 纯色山顶、透明背缘、草地图块完全沿用 v1；背缘仍保留原来的 53 个透明像素。
- 单图仍为 16×16，完整竖条仍为 16×96，配色不变。
- 草色 `#89A043`；山顶填充 `#B3995C`。原有四种岩色保留，不增加高光、渐变或新色。
- 所有单图外圈像素、山脚最后四行、山顶前缘最上六行都使用 v1 原像素，避免细节生成影响接缝和空白区域。

## 文件

`01-Foot-16x16.png`、`02-Wall-16x16.png`、`03-Summit-Front-16x16.png`、`04-Summit-16x16.png`、`05-Summit-Back-16x16.png` 为五张独立山体 tile；`06-Grass-16x16.png` 为原草地。

`Mountain-Front-16x96.png` 是六张无间隔竖排合图，自上向下顺序 **05 → 04 → 03 → 02 → 01 → 06**。

`Mountain-Detail-comparison.png` 左侧为 v1，右侧为 v2，均为整数 6 倍放大。棋盘格仅在预览中表示透明；原图没有棋盘格背景。

`Mountain-Front-native-tiles.zip` 包含六张单图、合图和本说明。

## 生成方式与完整提示词

使用 imagegen 技能的**内置 image_gen 编辑模式**，三个需要增加细节的部位各调用一次；没有使用 CLI/API fallback。完整提示词与输入路径保存于 `Prompts.json`。

输入为 v1 原生 16×16 tile 的整数放大图，不重新设计整体山形。`References/` 保留输入，`Sources/` 保留三张内置工具生成的细节源图。

`Assemble.ps1` 将生成源图限制在岩面可修改区域，使用原色板转换回 16×16，再与原版不变区域合成。初次格心采样会漏掉细裂纹，因此最终采用每格 4×4 子采样：生成的次要岩色至少覆盖 2/16 样点时保留为一个逻辑像素。所有新增纹理均来自生成源图，没有程序随机生成裂纹。背景、透明轮廓和接缝用原像素保护。

## 验证

- 三张细节图合计 59 个像素变化；其他三张单图逐字节复制原版。
- 五处接缝的 80 对像素一致。
- 合图全体 1,536 个像素的透明通道与 v1 一致，无新增半透明像素。
- 已查看最终 16×16 实际像素的放大对比，不以大尺寸生成源图代替验收。
