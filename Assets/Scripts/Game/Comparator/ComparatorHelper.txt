Comparator design

UnitValue
    Typed runtime value used by expressions.
    Supports Bool, Int, Float, Float2, Float3, and Entity.

ValueExpression
    Serialized value tree node.
    Literal: a fixed UnitValue.
    Getter: resolves a string key to a cached getter delegate.
    Operation: evaluates child expressions through IValueOperation.

ICompareType
    Declares an ordered parameter list and returns a boolean result.
    Example: GreaterThan(Number left, Number right).

IValueOperation
    Declares an ordered parameter list and a result category.
    Example: Distance(Float3 positionA, Float3 positionB) -> Number.

ComparatorFactory
    Builds a Comparator from condition configuration and a value resolver.
    It validates parameter counts and value categories once during construction.

IComparatorValueResolver
    Integration interface implemented later by the unit source access table.
    It maps getter keys to typed delegates.
