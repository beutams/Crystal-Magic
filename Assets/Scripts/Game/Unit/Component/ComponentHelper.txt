UnitAuthoringUtility
- Content
    Helper methods for resolving UnitData and UnitModuleData from prefabs.
- APIs
    GetUnitDataTableAsset: get the UnitData table asset.
    ResolveUnitData / ResolveModuleData: resolve data rows for the current prefab.
    GetPrefabAssetPath: read prefab asset path in editor baking stage.

NPCAuthoringUtility
- Content
    Helper methods for resolving NPCData from prefabs.
- APIs
    GetNpcDataTableAsset: get the NPCData table asset.
    ResolveNpcData: resolve NPCData by PrefabPath first, then fallback to NPC name.

NPCInteractableAuthoring
- Content
    Resolve NPC interaction data by prefab match during baking.
    InteractRange: interaction range.
    Interact: interaction marker transform.

NPCInteractionRequest
- Content
    Represents a singleton interaction request.

NPCInteractionState
- Content
    Tracks which NPC can currently be interacted with.
