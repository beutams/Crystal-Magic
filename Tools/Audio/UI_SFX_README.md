# Crystal Magic UI 音效试听版 v1

24 种原创程序合成短音效，未使用第三方采样，也不是录制的拟音或 AI 音频模型输出。设计方向为柔和木扣、纸页、金属与魔法铃音；纸张声音为风格化模拟。声音是否符合最终美术氛围仍需试听确认。

- 主文件：48 kHz、16-bit PCM、单声道 WAV，无循环，保留音量余量。
- 游戏资源位置：`Assets/Res/Audio/SFX/UI/`。
- 仅生成素材，没有绑定按钮事件或改变游戏音量设置。
- `ui-preview.wav` 按 01–24 顺序拼接，间隔 0.4 秒；起点见下表。
- 逐项试听面板内嵌无损压缩的同一份 WAV，解压后与主文件完全一致。
- 通用点击与专用动作声音只选一个；开书、翻页、装备、买卖等优先用专用音。
- 连续拾取、焦点切换、整理和滑杆操作应限频，避免堆叠。
- 血蓝条、施法进度、小地图、伤害数字、悬浮详情和加载进度保持静音。

## 重新生成

在项目中使用装有 numpy 的 Python：

```text
python Tools/Audio/generate_ui_sfx.py --preview <绝对路径/ui-audio-pack-v1.html>
```

若已存在同名 WAV，脚本默认拒绝覆盖；确认要重新生成后加 `--force`。种子固定，相同环境下可复现。ZIP 中 `source/` 保留完整生成源码；独立解压后脚本的输出根目录为其所在目录的上两级。
