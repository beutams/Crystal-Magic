# Crystal Magic：材质版 UI 音效完整 24 项

本次补齐 18 项；之前认可的点击、取消、翻页、放物品、装备、魔法嵌入 6 个 WAV 及其 Unity GUID 原样保留。初版的 24 个纯合成 WAV 也保留，不覆盖。

声音以木扣、纸页、皮革、锁扣、硬币和玻璃的动作感为主；新制 18 项不添加提示音阶、旋律或长混响。原六项中的魔法嵌入仍保留已认可的短合成气流层。成功结算用开启、落点、硬币展开；失败结算用收落、合盖、闷击。

## 位置与试听

- 游戏资源：`Assets/Res/Audio/SFX/UI_MaterialV2/`，现在共 24 个 WAV。
- `ui-material-new18.wav`：只听本次新增的 18 项，间隔 0.5 秒。
- `ui-material-full24.wav`：按最初 01–24 的分类顺序试听完整一套，间隔 0.5 秒。
- `preview-new-*.wav`：按通用、书本、物品、通知、结算、联机分组，只含新增项。
- 所有主文件为 48 kHz / 16-bit PCM / mono，非循环。试听音轨不额外改变主文件音量。
- `manifest.json` 给出编号、用途、试听起点、源音、具体裁切与处理参数、文件 SHA-256。
- 之前 6 项试听中的 01–06 是试样编号；本清单恢复最初 24 项的功能编号，文件名与声音未改。
- 当前仅更新素材和导入配置，没有新增 UI 播放绑定，也没有修改游戏音量设置。

## 音源与许可证

源素材来自 Kenney：

- RPG Audio：https://kenney.nl/assets/rpg-audio
- Impact Sounds：https://kenney.nl/assets/impact-sounds

两个包的原始 CC0 许可声明随 ZIP 提供，实际使用的源音放在 `source-audio/` 中。这些是授权音源的剪辑、变速、均衡、叠层与瞬态处理版本，不是原创实录或 AI 模型生成音频。

## 后续接入规则

同一个动作优先播放专用声音，不同时叠加通用点击；翻页不在重复点击当前页时触发；滑杆、悬停、连续拾取需要限频；交易、保存、装配和出发等在操作实际成功后触发。血蓝条、施法进度、小地图、悬浮详情和加载进度保持静音。

## 生成与验证

项目脚本 `Tools/Audio/build_ui_material_full.py` 使用本地已解码的 CC0 源音与已认可的 6 项清单补齐 18 项。脚本会先校验旧版和已认可文件，拒绝覆盖非一致的已有新文件，最后再次校验保护文件。ZIP 保留源码作参考，脚本依赖本项目的原 v1/v2 文件与目录，不是独立即用的工程。

程序验证覆盖格式、非静音、峰值余量、首尾零采样、直流偏移、唯一文件哈希、授权音源哈希和压缩包内容。技术验证不能代替结合动画及实际背景音乐的主观试听验收。
